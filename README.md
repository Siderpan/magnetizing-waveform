# MQ 磁環充磁波形模擬

等方向性 MQ（快淬 NdFeB 黏結磁）多極磁環的充磁模擬網頁工具：輸入磁環幾何、軛鐵、探棒位置、材料與充磁夾具參數，拖動充磁強度（每槽安匝 NI），即時看到磁環內表面的高斯波形 Bn。

## 功能

- 表面高斯波形（0° = N 極起點），可疊加飽和參考與「充磁時不裝軛鐵」對照
- 峰值、極中心值、牛角指標、基波振幅、THD、軛鐵磁通密度
- 單極面積（G·°）、N/S 單極面積、單極磁通估算
- 峰值與充飽體積比例對充磁強度的曲線
- 一對極截面的磁化方向分佈
- 每個專有名詞旁的「?」說明，附示意圖

## 模型

- 2D 多層磁荷法，軸向有限高度以 K1 Bessel 函數精確積分修正
- 夾具以槽內線電流表示（脈衝充磁時夾具鐵心視為飽和）
- 軛鐵充磁時以飽和磁通密度 Bs × 厚度限制其作用
- MQ 初始充磁曲線：M/Br = 1 − exp(−(H/H0)^1.8)，H0 ≈ 1.33·Hcj

數值適合比較趨勢與方案，絕對值請以實測校正。

## 使用

單一 HTML 檔，不需安裝：直接開啟 `index.html`，或瀏覽 https://siderpan.github.io/magnetizing-waveform/ 。輸入值只存在使用者自己的瀏覽器。
